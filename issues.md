# Clicking the project name opens the mission

## Problem

The project header bar shows the project name but does not offer a way
to read that project's `mission.md`.

## Behavior

Clicking the project name on the project bar opens a growable window
that shows the project's mission.

## Verification

Click the name on an open project's header: a resizable window shows
that project's `mission.md`. Do not pin prompt wording.

# Work Queue / lieutenant split is draggable

## Problem

The border between the Work Queue and the lieutenant chat is fixed.
The operator cannot give more room to one or the other.

## Behavior

That border is a vertical splitter. Dragging it resizes the Work Queue
and the lieutenant pane against each other.

## Verification

Drag the border between Work Queue and lieutenant: one grows, the other
shrinks. The board / rail split is unchanged. Do not pin prompt wording.
